<TabItem value="get">

Get the personal folder of the current user.

```sql
SELECT
id,
name,
parent_id,
children,
created_at,
created_by,
description,
is_scheduled,
item_type,
modified_at,
modified_by,
permissions
FROM sumologic.content.personal_folder
WHERE region = '{{ region }}' -- required unless SUMOLOGIC_ENVIRONMENT is set
;
```
