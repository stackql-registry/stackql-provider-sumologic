## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Get a transformation rule with the given identifier.

```sql
SELECT
id,
created_at,
created_by,
enabled,
modified_at,
modified_by,
rule_definition
FROM sumologic.transformation_rules.transformation_rules
WHERE id = '{{ id }}' -- required
AND region = '{{ region }}' -- required unless SUMOLOGIC_ENVIRONMENT is set
;
```
</TabItem>
<TabItem value="list">

Get a list of transformation rules in the organization. The response is paginated with a default limit of 100 rules per page.

```sql
SELECT
id,
created_at,
created_by,
enabled,
modified_at,
modified_by,
rule_definition
FROM sumologic.transformation_rules.transformation_rules
WHERE region = '{{ region }}' -- required unless SUMOLOGIC_ENVIRONMENT is set
AND limit = '{{ limit }}'
AND token = '{{ token }}'
;
```
</TabItem>
</Tabs>

## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Update an existing transformation rule. All properties specified in the request are replaced. Missing properties will remain the same.

```sql
UPDATE sumologic.transformation_rules.transformation_rules
SET 
rule_definition = '{{ rule_definition }}',
enabled = {{ enabled }}
WHERE 
id = '{{ id }}' --required
AND region = '{{ region }}' --required unless SUMOLOGIC_ENVIRONMENT is set
AND enabled = {{ enabled }} --required
AND rule_definition = '{{ rule_definition }}' --required
RETURNING
id,
created_at,
created_by,
enabled,
modified_at,
modified_by,
rule_definition;
```
</TabItem>
</Tabs>
