Get the full path of the mutingschedule or folder in the mutingSchedules library.

```sql
SELECT
path,
path_items
FROM sumologic.muting_schedules.paths
WHERE id = '{{ id }}' -- required
AND region = '{{ region }}' -- required unless SUMOLOGIC_ENVIRONMENT is set
;
```
