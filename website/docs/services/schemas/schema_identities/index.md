Get a summary of all available schema bases grouped by type and their versions sorted by latest.

```sql
SELECT
type,
versions
FROM sumologic.schemas.schema_identities
WHERE region = '{{ region }}' -- required unless SUMOLOGIC_ENVIRONMENT is set
;
```
